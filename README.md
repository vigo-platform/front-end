# Vigo Frontend

Frontend application for the Vigo platform, built with React, TypeScript, and Vite.

## Tech Stack

- React
- TypeScript
- Vite
- ESLint

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Production Build

```bash
npm run build
```

### Lint

```bash
npm run lint
```
